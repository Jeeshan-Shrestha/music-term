## Music Downloader from terminal 

### dependency 

- gcc
- yt-dlp

### how to install and use
```
- sudo chmod +x install.sh
- ./install.sh
- download-music "song-name"
```

for fedora
```
sudo dnf copr enable nara-nara/music-term
sudo dnf install music-term
```

### HOW TO USE

if u used install.sh
```sh
download-music "music_name"
```

if u downloaded from copr repo
```sh
music-term "music_name"
```
